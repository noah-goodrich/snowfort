# 20260612-snowfort-reposition-not-kill

## decision

Reposition snowfort as a six-pillar WAF scorecard tool and ship as a CoCo MCP Skill, rather than deprecating it

## context

Post-Summit-2026 review raised the question of whether snowfort had a viable future; deep-research + 5-persona council was run to evaluate options

## reasoning

The WAF scorecard angle gives snowfort a defensible niche; shipping as a CoCo MCP Skill creates a moat via integration rather than standalone utility. Reveal was identified as the template for this approach.

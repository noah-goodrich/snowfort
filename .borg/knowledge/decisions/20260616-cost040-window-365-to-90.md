# 20260616-cost040-window-365-to-90

## decision

## context

COST_040 scans ACCESS_HISTORY to identify unused objects; 365-day window was excessively broad

## reasoning

90 days captures meaningful recent usage patterns while dramatically reducing the scan scope and query cost against Snowflake's ACCESS_HISTORY view, which is expensive to query at scale

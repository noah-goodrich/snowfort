# obs-20260414-dcm-projects-preview

## content

DCM Projects — Snowflake's native IaC feature — entered Preview in March 2026. It is a viable lightweight alternative to Terraform for Snowflake resource management, particularly at early-stage scale where Terraform's state management overhead is unjustified.

## resolution

Evaluate DCM Projects as the primary IaC path for new Snowflake projects. Note it is still in Preview as of the session date; monitor for GA promotion before adopting in production-critical workflows.
